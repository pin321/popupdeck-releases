# PopupDeck downloads

This repository holds the downloadable builds of **PopupDeck**, a pop-up macro deck for Windows.
There is no source code here.

## Get the app

Go to **[Releases](https://github.com/pin321/popupdeck-releases/releases)** and download the
`PopupDeck-...-win-x64.exe` file of the newest release. There is no installer: the file is the app.

- 64-bit Windows 10 or 11
- Fully offline: PopupDeck never connects to the internet and collects no data
- Free 7-day trial

Early builds are not code-signed yet, so Windows shows "Windows protected your PC" the first time.
Click **More info**, then **Run anyway**. Each release lists the file's SHA-256 checksum so you can
check your download.
